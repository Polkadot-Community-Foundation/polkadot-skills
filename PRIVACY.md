# Privacy

Polkadot Skills is a set of Markdown instructions for coding agents. It contains no code that runs on your
machine, no server and no analytics.

- **No user data.** The skills do not collect, store or send any personal data, usage data or telemetry.
  The Polkadot Community Foundation receives nothing when you install or use them.
- **Your agent and its provider.** The skills are read by the coding agent you choose (for example Claude
  Code, Codex or Cursor). That agent and its provider handle your prompts and files under their own
  privacy policies.
- **Install tools and marketplaces.** The tool or marketplace you install from (for example the `skills`
  CLI or a plugin directory) may record installs under its own privacy policy.
- **Apps you build.** Apps built with these skills run on Polkadot networks. What those apps collect is up
  to whoever builds and runs them.
